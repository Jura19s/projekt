O projektu

VektorSec je responzivna web-stranica namijenjena predstavljanju usluga kibernetičke sigurnosti i zaštite poslovnih sustava.

Glavne funkcionalnosti

Pregled usluga i načina rada.

Predstavljanje tima, industrija i primjera projekata.

Članci, cjenik i često postavljena pitanja (FAQ).

Kontaktna forma i prijava na newsletter.

Responzivna navigacija za mobilne uređaje.

Skočni prozori, animacije, brojači i obavijest o kolačićima.

Tehnologije

HTML – struktura stranice.

CSS – dizajn i prilagodba različitim zaslonima.

JavaScript – interaktivne funkcionalnosti.

PHP – uključivanje zajedničkog zaglavlja i podnožja.

Pokretanje

Smjestiti datoteku u web-poslužitelj koji podržava PHP.

Osigurati da se datoteke zaglavlje.php i podnozje.php nalaze na očekivanoj lokaciji.

Otvoriti stranicu kroz lokalni ili javni web-poslužitelj.

Napomene

Prije objave zamijeniti ogledne podatke o timu, kontaktne adrese i statistike stvarnim podacima. Kontaktna forma trenutačno samo simulira slanje poruke, pa je potrebno povezati je s backendom ili servisom za obradu obrazaca. Provjeriti i konfigurirati slanje newslettera.

Cilj

Pružiti moderan i pregledan prikaz usluga VektorSeca te omogućiti posjetiteljima jednostavno pronalaženje informacija i slanje upita.
